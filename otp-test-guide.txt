OTP MODULE TESTING GUIDE
======================

1. SETUP ETHEREAL EMAIL:
   - Go to https://ethereal.email and create an account
   - Copy the username and password provided

2. UPDATE .env FILE:
   EMAIL_HOST=smtp.ethereal.email
   EMAIL_PORT=587
   EMAIL_USER=[your_ethereal_username]
   EMAIL_PASS=[your_ethereal_password]
   EMAIL_FROM=noreply@linkprosoft.com
   EMAIL_SECURE=false

3. BUILD THE PROJECT:
   npm run build

4. SEND TEST OTP:
   Run: node -e "require('dotenv').config(); const otpService = require('./dist/modules/otp/otpService'); const userId = Math.random().toString(36).substring(2,15) + Math.random().toString(36).substring(2,15); const testEmail = 'test-otp-' + Date.now() + '@example.com'; console.log('User ID: ' + userId); otpService.generateAndSendOtP(userId, testEmail, 'email_verification', {}).then(({otpId, isResend}) => {console.log('OTP sent. Check email at ' + testEmail); console.log('OTP ID: ' + otpId);});"

5. CHECK EMAIL FOR CODE:
   Login to https://ethereal.email with your credentials
   Find the test email and note the 6-digit OTP code

6. VERIFY OTP:
   Run: node -e "require('dotenv').config(); const otpService = require('./dist/modules/otp/otpService'); const userId = '[USER_ID_FROM_STEP_4]'; const otpCode = '[OTP_CODE_FROM_EMAIL]'; otpService.verifyOtP(userId, 'email_verification', otpCode, {}).then(isValid => {if (isValid) console.log('SUCCESS: OTP verification passed.'); else console.log('FAILURE: OTP verification failed.'));});"
