# Thunder Client Quick Reference — Phase 3

Quick list of common requests to run manually after importing the collection.

- `POST /api/jobs` — Create job
- `GET /api/jobs` — List jobs (filters: skill, location, status)
- `POST /api/assignments` — Invite professional
- `PUT /api/assignments/:id/accept` — Accept assignment
- `PUT /api/assignments/:id/start` — Start assignment
- `PUT /api/assignments/:id/complete` — Complete assignment

Include example bodies in the Thunder Client collection for quick copy-paste.
